HYPOTHESIS: Output only the argmax class per eval box (one row, score = conf × p_argmax) instead of all four class rows. Currently every box emits up to 4 rows, and the ~3 non-argmax rows are almost always false positives for their class (a box overlaps at most one true box, and its other-class rows can never match it), yet they still interleave into each class's ranking because a high-conf box's second row can outrank a low-conf box's top row. Dropping them should sharply improve precision at every recall level, especially for the weak pore/stain classes which receive many spurious deposit/pore rows; the few true boxes whose argmax is wrong lose only a low-ranked row. This differs from e004 (temperature), which rescaled the scores of the same four rows and hurt: here we change *which* rows exist, not their values. Expected gain ≥0.01.
