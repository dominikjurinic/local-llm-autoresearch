Mixup implementation:

```
def mixup(xt, xw, y, lam):
    # xt, xw: (B,3,H,W) float on device; y: (B,) long
    b = xt.size(0)
    idx = torch.randperm(b, device=xt.device)
    xt = lam * xt + (1 - lam) * xt[idx]
    xw = lam * xw + (1 - lam) * xw[idx]
    y_a, y_b = y, y[idx]
    return xt, xw, y_a, y_b, lam
```
