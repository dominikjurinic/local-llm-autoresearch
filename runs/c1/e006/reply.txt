These classes differ mainly by their true physical scale (pore small, deposit local, stain diffuse), but the current crop is normalised to the box long-side, so a small pore and a large stain both fill the same fraction of the 160px frame and the model cannot see the scale. I add the box long-side (pixels) and aspect ratio as two constant input channels (in_chans=5, init 0 so pretraining is preserved) and the detector conf as a third, giving the network the absolute-size and box-quality signals it currently lacks. def box_feats(r):
    ls = float(max(r["x2"] - r["x1"], r["y2"] - r["y1"], 1.0))
    ar = float((r["x2"] - r["x1"]) / max(r["y2"] - r["y1"], 1e-6))
    conf = float(r.get("conf", 0.5))
    return np.array([
        float(np.interp(ls, LOG_SIDE[0], np.arange(256) / 255.0)),
        float(np.interp(ar, LOG_SIDE[1], np.arange(256) / 255.0)),
        float(np.interp(max(conf, 1e-4), LOG_CONF, np.arange(256) / 255.0)),
    ], dtype=np.float32)
