## Background
LoHi-WELD contains images of real robotic weld beads with four defect types:
0 pore, 1 deposit, 2 discontinuity, 3 stain. The original paper uses a one-step detector
(YOLOv7-tiny) that finds and names defects at once: 0.69 mAP@0.5 on high-res images. When all

not missed defects.

We test a two-stage system: a class-agnostic detector (stage 1, fixed, already run) finds candidate
boxes with a confidence `conf`; your code (stage 2) decides the type of each box and gives each
prediction a score.

## How the score works (facts about the metric)
- mAP@0.5 is computed per class and averaged. For one class, all predictions of that class are
  sorted by score; a prediction is a hit if it overlaps an unmatched true box of that class by IoU > 0.5.
  AP depends only on this ORDER. Any change that keeps the order of a class's predictions (for
  example multiplying all its scores by a constant, or a monotone function of the score) leaves its
  AP unchanged.
- Several rows per box (one per class) are allowed; per image at most the 300 highest-scoring rows count.
- Detector boxes include false alarms and slightly misplaced boxes.

## Background reading: general techniques (not specific to this dataset)

These are general techniques from the literature, with the conditions under which they tend to help or hurt.
None of it is specific to this dataset; whether any of it helps here is for your experiments to show.

### Second-stage classifiers in two-stage detection
- R-CNN-family detectors train the second stage on the first stage's own proposals, labelled by overlap with
  ground truth (e.g. IoU >= 0.5 positive, < 0.5 background), usually sampling positives and background in a fixed
  ratio (Faster R-CNN: up to 1:3). Training on proposals instead of perfect boxes matches the test distribution.
  (Ren et al., Faster R-CNN, 2015)
- Cascade R-CNN shows that a classifier trained at one IoU threshold is best for boxes of that quality; box
  quality at training and test time should match. (Cai & Vasconcelos, 2018)
- When the first stage already ranks objects well, the final score is often the product of the first-stage
  confidence and the second-stage class probability; how the two are combined changes the ranking only where the
  classifier's probabilities differ between boxes.

### Fine-grained recognition of small objects
- Distinguishing visually similar classes usually depends on fine texture; input resolution and how much of the
  crop the object fills both matter. Pretrained backbones are typically trained at a fixed resolution and often
  work best near it. (Touvron et al., "Fixing the train-test resolution discrepancy", 2019)
- Context around an object can help separate classes that look alike up close; several views at different
  scales can be combined (multi-scale or multi-crop inputs), at a proportional compute cost.

### Training under a fixed time budget
- With a hard wall-clock budget, the number of optimisation steps is limited; a smaller or faster model, lower
  resolution, or fewer views can win over a stronger but slower one, and the reverse can also hold.
  Learning-rate schedules that decay to zero by the end of the budget usually beat schedules designed for longer
  training. (Li, Yumer & Ramanan, "Budgeted Training", 2020)
- Data loading and image decoding can be the bottleneck rather than the GPU; caching or pre-cropping can buy
  steps. Mixed precision and channels-last memory format speed up convolutional networks on recent GPUs.
- Efficient backbone families trade accuracy against speed differently (EfficientNet / EfficientNetV2,
  MobileNetV3, RegNet, ConvNeXt); some need different learning rates or warm-up to fine-tune stably.

### Variance reduction: ensembles, averaging, test-time augmentation
- Averaging the predictions of several independently trained models is one of the most reliable ways to improve
  accuracy and calibration, at a linear cost in compute. (Lakshminarayanan et al., Deep Ensembles, 2017)
- Cheaper variants: snapshot ensembles from one training run (Huang et al., 2017), weight averaging along the
  trajectory (SWA, Izmailov et al., 2018), and test-time augmentation (averaging over flips or crops).
- Under a fixed budget, an ensemble means less training per member; the trade-off depends on how undertrained
  each member is.

### Losses, regularisation and data
- Focal loss helps dense detectors with extreme foreground/background imbalance (Lin et al., 2017); for a crop
  classifier with moderate imbalance its benefit is less clear.
- Label smoothing improves calibration in some settings but can reduce the information in class probabilities
  that ranking metrics use (Muller, Kornblith & Hinton, 2019).
- Mixup and CutMix regularise strongly and typically need longer training to pay off (Zhang et al., 2018;
  Yun et al., 2019).
- Adding data from a different source or resolution can help or hurt depending on how different it is from the
  test data (domain shift).

### Ranking metrics
- Average precision depends only on the order of predictions within each class. Any transformation that keeps
  that order (scaling, temperature, most monotone functions) leaves AP unchanged; changes help only if they
  re-order true detections above false ones.
- Temperature scaling and other calibration methods fix probability levels, not rankings (Guo et al., 2017).

### Experimental practice
- Single runs of a neural network vary with the seed; small differences need several seeds to be trusted.
- A result far below the baseline usually indicates a bug (wrong preprocessing, label order, untrained model)
  rather than a bad idea; checking the training loss and a few predictions often finds it.
- Locating the error first (which classes are confused, which sizes fail, how much is lost to ranking vs.
  classification) tends to point to the change with the largest effect.

#!/usr/bin/env python3
"""
Two-stage weld defect detection, stage 2: the file the research agent edits.

Stage 1 (fixed, already done): a class-agnostic detector (YOLOv7-tiny) found candidate defect boxes,
each with a confidence ("conf"). Stage 2 (this file): decide the defect type of each box and give
each prediction a score: 0 pore, 1 deposit, 2 discontinuity, 3 stain.
The result is scored like a normal detector: mAP at IoU 0.5 over the 4 classes.

Contract with the harness (do not break it):
  - inputs in <data>:
      crops.csv  labelled training boxes: id, res ("high"/"low"), image, x1, y1, x2, y2, img_w, img_h, cls
      dets.csv   detector boxes: det_id, split ("train" or "eval"), image, x1, y1, x2, y2, img_w, img_h, conf
                 "train" boxes are on training images (their true class can be found by overlap with crops.csv);
                 "eval" boxes are on hidden evaluation images: make predictions for these
      images/    the images
  - write <out>/preds.csv with columns det_id, cls, score: one or more rows per eval box
    (several rows with different classes for the same box are allowed; leaving a box out drops it).
    Higher score = more confident. Per image at most the 300 highest-scoring rows count.
  - use --seed for all randomness
  - finish within --seconds of wall time (loading, training, prediction); the harness kills it at the limit.

Starting point: the "two-crop" classifier (tight crop 1.5x + wide crop 2.5x of the box through the same
EfficientNet-B0, logits averaged), trained on the true training boxes; each eval box becomes one
prediction per class with score = detector conf x class probability.
"""
import time

T0 = time.time()  # the time budget counts from here

import argparse
import csv
import math
import os
import random

import numpy as np
import timm
import torch
import torch.nn as nn
from PIL import Image

# ---------------------------------------------------------------- settings
MODEL = "efficientnet_b0"
PRETRAINED = True
IMG_SIZE = 160
CONTEXT = 2.5           # wide crop: side = CONTEXT * long side of the box
TIGHT_CONTEXT = 1.5     # tight crop
MIN_CROP = 16
TRAIN_ON = ("high",)    # resolutions of crops.csv used for training
BATCH_SIZE = 64
LR = 1e-3
WEIGHT_DECAY = 0.05
RESERVE_S = 55          # seconds kept free for prediction and writing
MIN_SCORE = 0.001       # rows below this score are not written
MEAN = np.array([0.485, 0.456, 0.406], dtype=np.float32)
STD = np.array([0.229, 0.224, 0.225], dtype=np.float32)


def read_csv(path):
    rows = list(csv.DictReader(open(path)))
    for r in rows:
        for k in ("x1", "y1", "x2", "y2", "conf"):
            if k in r:
                r[k] = float(r[k])
        if "cls" in r:
            r["cls"] = int(r["cls"])
    return rows


def make_crop(img, r, context, train):
    h, w = img.shape[:2]
    cx, cy = (r["x1"] + r["x2"]) / 2, (r["y1"] + r["y2"]) / 2
    side = max(max(r["x2"] - r["x1"], r["y2"] - r["y1"]) * context, MIN_CROP)
    if train:  # light geometric jitter
        cx += random.uniform(-0.1, 0.1) * side
        cy += random.uniform(-0.1, 0.1) * side
        side *= random.uniform(0.85, 1.2)
    s = max(2, int(round(side)))
    x0, y0 = int(round(cx - s / 2)), int(round(cy - s / 2))
    canvas = np.full((s, s, 3), 114, dtype=np.uint8)  # gray padding outside the image
    sx0, sy0, sx1, sy1 = max(0, x0), max(0, y0), min(w, x0 + s), min(h, y0 + s)
    if sx1 > sx0 and sy1 > sy0:
        canvas[sy0 - y0:sy1 - y0, sx0 - x0:sx1 - x0] = img[sy0:sy1, sx0:sx1]
    return np.asarray(Image.fromarray(canvas).resize((IMG_SIZE, IMG_SIZE), Image.BILINEAR), dtype=np.float32) / 255.0


class BoxDataset(torch.utils.data.Dataset):
    def __init__(self, rows, images, train):
        self.rows, self.images, self.train = rows, images, train

    def __len__(self):
        return len(self.rows)

    def __getitem__(self, i):
        r = self.rows[i]
        img = self.images[r["image"]]
        fh = fv = False
        bright = 1.0
        if self.train:  # same flips and brightness for both views
            fh, fv, bright = random.random() < 0.5, random.random() < 0.5, random.uniform(0.8, 1.2)
        views = []
        for ctx in (TIGHT_CONTEXT, CONTEXT):
            x = make_crop(img, r, ctx, self.train)
            if fh:
                x = x[:, ::-1]
            if fv:
                x = x[::-1, :]
            if self.train:
                x = np.clip(x * bright, 0, 1)
            x = (x - MEAN) / STD
            views.append(torch.from_numpy(np.ascontiguousarray(x.transpose(2, 0, 1))))
        return views[0], views[1], r.get("cls", -1)


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--data", default="/work/data")
    ap.add_argument("--out", default="/work/out")
    ap.add_argument("--seed", type=int, default=0)
    ap.add_argument("--seconds", type=float, default=180)
    args = ap.parse_args()
    deadline = T0 + args.seconds
    random.seed(args.seed); np.random.seed(args.seed); torch.manual_seed(args.seed)
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

    crops = [r for r in read_csv(os.path.join(args.data, "crops.csv")) if r["res"] in TRAIN_ON]
    dets = read_csv(os.path.join(args.data, "dets.csv"))
    ev = [d for d in dets if d["split"] == "eval"]
    needed = {r["image"] for r in crops} | {d["image"] for d in ev}
    images = {p: np.asarray(Image.open(os.path.join(args.data, "images", p)).convert("RGB")) for p in needed}
    print(f"train {len(crops)} boxes, eval {len(ev)} detections, {len(images)} images ({time.time() - T0:.0f}s)", flush=True)

    workers = min(8, os.cpu_count() or 2)

    def worker_init(_):
        s = torch.initial_seed() % 2**32
        random.seed(s); np.random.seed(s)

    g = torch.Generator().manual_seed(args.seed)
    dl_tr = torch.utils.data.DataLoader(BoxDataset(crops, images, True), batch_size=BATCH_SIZE, shuffle=True,
                                        num_workers=workers, pin_memory=True, drop_last=True,
                                        persistent_workers=True, generator=g, worker_init_fn=worker_init)
    dl_ev = torch.utils.data.DataLoader(BoxDataset(ev, images, False), batch_size=256, shuffle=False,
                                        num_workers=workers, pin_memory=True)

    model = timm.create_model(MODEL, pretrained=PRETRAINED, num_classes=4)
    model = model.to(device).to(memory_format=torch.channels_last)
    crit = nn.CrossEntropyLoss()
    opt = torch.optim.AdamW(model.parameters(), lr=LR, weight_decay=WEIGHT_DECAY)
    amp = dict(device_type=device.type, dtype=torch.bfloat16, enabled=device.type == "cuda")

    # Train until the budget minus the reserve is used up: 5% warm-up, then cosine decay.
    t_start = time.time()
    t_end = deadline - RESERVE_S
    budget = max(1.0, t_end - t_start)
    steps, epoch, done = 0, 0, False
    model.train()
    while not done:
        tot, nb = 0.0, 0
        for xt, xw, y in dl_tr:
            frac = min(1.0, (time.time() - t_start) / budget)
            f = frac / 0.05 if frac < 0.05 else 0.5 * (1 + math.cos(math.pi * (frac - 0.05) / 0.95))
            for pg in opt.param_groups:
                pg["lr"] = LR * max(f, 1e-3)
            xt = xt.to(device, non_blocking=True).to(memory_format=torch.channels_last)
            xw = xw.to(device, non_blocking=True).to(memory_format=torch.channels_last)
            y = y.to(device, non_blocking=True)
            with torch.autocast(**amp):
                loss = crit((model(xt) + model(xw)) / 2, y)
            opt.zero_grad(set_to_none=True)
            loss.backward()
            opt.step()
            tot += loss.item(); nb += 1; steps += 1
            if time.time() >= t_end:
                done = True
                break
        print(f"epoch {epoch}: loss {tot / max(nb, 1):.4f}, {steps} steps, {time.time() - T0:.0f}s", flush=True)
        epoch += 1

    # Classify every eval detection; one prediction per class with score = detector conf x class probability.
    model.eval()
    probs = []
    with torch.no_grad(), torch.autocast(**amp):
        for xt, xw, _ in dl_ev:
            xt = xt.to(device).to(memory_format=torch.channels_last)
            xw = xw.to(device).to(memory_format=torch.channels_last)
            probs.append(torch.softmax(((model(xt) + model(xw)) / 2).float(), 1).cpu())
    probs = torch.cat(probs).numpy()
    os.makedirs(args.out, exist_ok=True)
    n = 0
    with open(os.path.join(args.out, "preds.csv"), "w", newline="") as f:
        w = csv.writer(f)
        w.writerow(["det_id", "cls", "score"])
        for d, p in zip(ev, probs):
            for c in range(4):
                s = d["conf"] * float(p[c])
                if s > MIN_SCORE:
                    w.writerow([d["det_id"], c, f"{s:.6f}"]); n += 1
    print(f"done: {epoch} epochs, {steps} steps, {n} prediction rows, {time.time() - T0:.0f}s total", flush=True)


if __name__ == "__main__":
    main()
