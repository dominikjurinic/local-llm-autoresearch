Let me analyze the crash in e019. The error is:
```
RuntimeError: Input type (torch.cuda.DoubleTensor) and weight type (CUDABFloat16Type) should be the same
```

The issue is that `np.random.normal(0, noise_sigma, x.shape)` produces a float64 (double) array by default. When this is added to `x` (which is float32), the result becomes float64. Then when converted to a torch tensor and moved to CUDA, it's a DoubleTensor, which conflicts with the bfloat16 weights.

The fix is to ensure the noise is generated as float32: `np.random.normal(0, noise_sigma, x.shape).astype(np.float32)`.
