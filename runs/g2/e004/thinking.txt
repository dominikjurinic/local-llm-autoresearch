Actually, I want to reconsider the hypothesis. The key question is: why should concatenating features help more than averaging logits?

Averaging logits: The model produces 4-dim logits for each view, and we average them. This means the model has to make a full classification decision for each view independently, and then we combine the decisions. Information is lost in the 4-dim bottleneck.

Concatenating features: The model produces 1280-dim features for each view, we concatenate them to 2560-dim, and then a head makes the classification. The head can learn to use complementary information from the two views. For example, if the tight view shows fine texture (pore-like) but the wide view shows a stain-like context, the head can learn to weigh these appropriately.

This should especially help with the pore/stain and deposit/stain confusions, because:
- Pores are small, round, dark spots. The tight view captures this well.
- Stains are larger, more diffuse areas. The wide view captures this better.
- By seeing both views' features simultaneously, the model can better distinguish them.

This is fundamentally different from the jitter and detector-box experiments because it changes how the model processes the two views, not what data it sees or how the boxes are sampled.
