CATEGORY: inference
HYPOTHESIS: The loss is not in the classifier's accuracy on the overlap set but in how detector confidence (from YOLO) and the classifier's probability are combined for ranking. Multiplying by conf pushes false alarms high, and it assumes the detector conf correlates with classification confidence which it may not. A proper ensemble of two classifiers trained from different seeds averages out variance and is expected to raise mAP@0.5 by ~0.02.
PLAN: 
1. Create a second training set with different random seed; run the same training loop for each model in sequence.
2. For inference, produce per-class probabilities from both models (same two-crop inputs).
3. Average the raw logits of the two models before softmax to get final class probabilities.
4. Score each prediction as conf * p_avg - keeping order but improving calibration.
5. Verify total time: 2x model training within budget, no extra inference cost beyond small constant.
