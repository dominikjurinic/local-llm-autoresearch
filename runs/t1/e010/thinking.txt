New FusionModel with 3 views and per-class attention:
```python
class FusionModel(nn.Module):
    """EfficientNet-B0 backbone with learnable per-class attention over three views."""
    def __init__(self, base, n_views=3):
        super().__init__()
        self.base = base
        self.attn = nn.Parameter(torch.zeros(4, n_views))  # per-class, per-view; softmax

    def forward(self, views):
        # views: list of tensors, each (B, 3, H, W)
        logits = [self.base(v) for v in views]  # each (B, 4)
        stacked = torch.stack(logits, dim=1)  # (B, n_views, 4)
        w = torch.softmax(self.attn, dim=1)  # (4, n_views)
        # per-class weighted sum: for each class c, sum_v w[c, v] * stacked[:, v, c]
        # stacked is (B, V, 4); w is (4, V). We want out (B, 4) where out[:, c] = sum_v stacked[:, v, c] * w[c, v]
        out = torch.einsum("bvc, cv -> bc", stacked, w)
        return out
```

Wait, let me check the einsum. `stacked` has shape (B, V, C) where V=3 views, C=4 classes. `w` has shape (C, V) = (4, 3). We want `out` of shape (B, C) where `out[b, c] = sum_v stacked[b, v, c] * w[c, v]`.

`torch.einsum("bvc, cv -> bc", stacked, w)`:
- b: batch
- v: view
- c: class
- For output bc, we sum over v: stacked[b, v, c] * w[c, v]. Yes, that's correct.

Actually wait, `w` is indexed as `cv` meaning first index c, second index v. `w[c, v]`. And `self.attn` is (4, 3) = (C, V), so `w[c, v]` = attn[c, v]. Good.

Let me double check: `self.attn = nn.Parameter(torch.zeros(4, n_views))` = shape (4, 3) = (C, V). `torch.softmax(self.attn, dim=1)` = softmax over V (dim 1), so each class's weights sum to 1 over the 3 views. Good, this is the per-class attention normalized within each class.
