HYPOTHESIS: Pore→stain and deposit→stain confusion costs ~0.10 mAP; both classes are misread as stain, while true stain is already 90% right. A box's area relative to the image (box-area ratio) is a strong geometric cue — pores are small/compact, deposits medium, stains large — that the appearance-only classifier never uses. Adding a per-class geometric head and combining its class-conditional score with the appearance logit re-orders exactly these confusions. This differs from the exhausted "box size as extra input" family (2 crashes, 1 edit failure, 1 run only at 0.629) by being a *second classification head* fused via scores rather than an input feature, and from e011's dedicated high-res stream (which hurt) by keeping the backbone identical and only adding a small regression head. Note: the "second head" is implemented as a parametric per-class geometric prior (Gaussian on log area-ratio, learned from training data) rather than a neural regression head, because a neural regression head predicting a single scalar cannot produce class-specific scores; the parametric prior is the minimal correct realisation of "per-class geometric score fused via scores" and carries zero crash risk.

MIN_SCORE = 0.001       # rows below this score are not written
MEAN = np.array([0.485, 0.456, 0.406], dtype=np.float32)
STD = np.array([0.229, 0.224, 0.225], dtype=np.float32)
GEO_CLIP = 0.05         # clip per-class geometric prior to [GEO_CLIP, 1/GEO_CLIP] so it modulates, not dominates


def log_area_ratio(r):
    area = max(1e-8, (r["x2"] - r["x1"]) * (r["y2"] - r["y1"]))
    img_area = max(1e-8, r["img_w"] * r["img_h"])
    return math.log(area / img_area)


def compute_class_geo_stats(crops):
    """Per-class mean/std of log(box_area / image_area) from training boxes."""
    stats = {}
    for c in range(4):
        vals = np.array([log_area_ratio(r) for r in crops if r["cls"] == c], dtype=np.float64)
        if len(vals) > 2:
            stats[c] = (float(vals.mean()), max(float(vals.std()), 0.1))
        else:
            stats[c] = (0.0, 1.0)
    return stats


def geo_score(log_r, mean_c, std_c):
    raw = math.exp(-0.5 * ((log_r - mean_c) / std_c) ** 2)
    return max(GEO_CLIP, min(1.0 / GEO_CLIP, raw))
