HYPOTHESIS: The classifier is trained on perfectly-centered ground-truth boxes but must classify stage-1 detector boxes, which are often offset or sized differently — a training/test distribution mismatch. Training on the actual proposed boxes (labelled by IoU with GT) instead of the perfect crops should match the test distribution and raise accuracy where it matters most: deposit↔stain and pore confusion. This differs from earlier attempts by using detector boxes as the primary training set rather than as a small auxiliary add-on, so the mismatch is targeted directly.
PLAN: 1) In read_csv of dets.csv, take the "train" split rows (they carry no cls but overlap with crops.csv true defects). For each train-split detector box, compute IoU with all crops.csv boxes on the same image; if max IoU > 0.5 it is positive with that GT class, otherwise negative (background row for every class or keep it out of positives). Use a helper that maps box pairs by image.
2) Replace the BoxDataset training rows with this new list: [gt_box] ∪ [detector_proposal]. To keep it simple, generate a new "crops" list containing both the original GT rows (labelled, unchanged two-crop input) and the matched detector boxes (same label as their IoU-matched GT box).
3) Do not change the model, resolution, or crops size; keep everything else identical so the only change is what the classifier sees during training. Expected gain: +0.015 to +0.03 in val mAP@0.5 by fixing the deposit/stain and pore errors directly.
4) Time budget: same model, same resolution, same step count — no expected time increase; keep the current 180 s budget with 55 s reserve.
