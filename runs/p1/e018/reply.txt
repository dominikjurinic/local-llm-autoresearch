HYPOTHESIS: The dominant loss is class confusion on true defects (pore 63% right, deposit 77% right, both often read as "stain"). I hypothesise this is a data-quality problem, not a capacity problem: the model learns pore/deposit/stain from clean ground-truth boxes but must classify stage-1 detector boxes whose offsets/sizes differ. The previous mix of GT and detector boxes in one pass gave only +0.004. A two-phase approach — train on clean GT boxes first, then fine-tune on detector boxes with IoU-based labels that also hard-sample the confusing false alarms — directly adapts the classifier to the detector distribution and should close most of the ~0.10 mAP gap. This differs from earlier runs by training the two distributions sequentially rather than mixing them in one pass. (Smallest fixes to the plan as written: (a) the current code uses AdamW, not SGD, so I keep AdamW + the existing cosine schedule rather than swap optimisers; (b) the "extra negative class" is implemented as a 5th background class in the head, but at inference I re-normalise over the 4 defect classes only, so the scoring stays exactly the current best's `conf * p_c` and I do not re-introduce the failed `conf*p_c*(1-p_bg)` ranking from the background-class family — the background class only shapes training so the model learns to reject false alarms.)

    # Label train-split detector boxes by IoU > 0.5 overlap with a ground-truth crop; unmatched -> background.
    by_img = {}
    for r in crops:
        by_img.setdefault(r["image"], []).append(r)

    def det_label(d):
        for r in by_img.get(d["image"], ()):
            ix1, iy1 = max(d["x1"], r["x1"]), max(d["y1"], r["y1"])
            ix2, iy2 = min(d["x2"], r["x2"]), min(d["y2"], r["y2"])
            inter = max(0.0, ix2 - ix1) * max(0.0, iy2 - iy1)
            if inter <= 0:
                continue
            area_d = (d["x2"] - d["x1"]) * (d["y2"] - d["y1"])
            area_r = (r["x2"] - r["x1"]) * (r["y2"] - r["y1"])
            if inter / max(1e-9, min(area_d, area_r)) > 0.5:
                d["cls"] = r["cls"]
                return
        d["cls"] = BG_CLASS

    for d in tr_dets:
        det_label(d)
