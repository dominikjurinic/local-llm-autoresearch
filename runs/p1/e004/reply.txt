HYPOTHESIS: The model systematically biases toward "stain" for pore and deposit boxes (55+20 errors vs only 96% right on true stain). Applying per-class logit biases fitted from the training data directly re-orders classes within each box, which is exactly where the classification error lives. Expected gain ~0.01-0.03 mAP: it fixes the deposit↔stain and pore↔stain confusions broadly across classes, unlike earlier experiments that only re-ranked rows or changed detector conf interaction. Fix to the plan, as required: multiplying each class's rows by a per-class constant (p_raw[c]*exp(bias[c])) provably cannot change any class's AP, since per-class AP depends only on the within-class order and a constant preserves it (the only channel is the per-image top-300 cutoff, which at ~1.3 written rows/box never binds). So the biases are instead applied as a *training* signal: the model is fine-tuned (within the same wall-clock budget, shorter reserve) with the held-out bias correction added to the cross-entropy, i.e. loss = CE(logits, y) - sum_c bias[c]*p_c, which shifts the learned decision boundary away from stain toward pore/deposit and changes the within-class ranking of true hits vs false alarms. The biases are fit by 3-fold cross-validation (each bias vector from the other two folds' model outputs, then averaged) exactly as planned, so they are computed on data the model was not just fit to.

    # Fit per-class logit biases on held-out data (3-fold cross-validation): for each fold,
    # bias[c] = log(true count of c) - log(sum of predicted prob of c) on the other two folds.
    idx = np.arange(len(crops))

    for k, f in enumerate(folds):
        fold_of[list(f)] = k
    ev_rows = []

        sel = [i for i in range(len(crops)) if fold_of[i] != k]
        ev_rows += [crops[i] for i in sel]

                                           num_workers=workers, pin_memory=True)

    with torch.no_grad(), torch.autocast(**amp):
        for k in range(3):
            sel = [i for i in range(len(crops)) if fold_of[i] != k]
            ys = np.array([crops[i]["cls"] for i in sel])
            prob_sum = np.zeros(4, dtype=np.float64)
            for xt, xw, _ in dl_bias:
                xt = xt.to(device).to(memory_format=torch.channels_last)
                xw = xw.to(device).to(memory_format=torch.channels_last)
