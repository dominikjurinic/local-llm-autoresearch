Let me now think about the IoU matching. I need, for each train det, find GT crops on the same image with IoU > 0.5, and assign the class. If multiple, pick the one with max IoU. Let me write a function.

```python
def iou(a, b):
    # a, b are (x1, y1, x2, y2)
    ax1, ay1, ax2, ay2 = a
    bx1, by1, bx2, by2 = b
    ix1, iy1 = max(ax1, bx1), max(ay1, by1)
    ix2, iy2 = min(ax2, bx2), min(ay2, by2)
    iw = max(0.0, ix2 - ix1)
    ih = max(0.0, iy2 - iy1)
    inter = iw * ih
    ua = (ax2 - ax1) * (ay2 - ay1) + (bx2 - bx1) * (by2 - by1) - inter
    return inter / ua if ua > 0 else 0.0
```
